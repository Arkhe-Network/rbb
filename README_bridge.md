# Bridge Integration Details

This project is delivering an integration of Cathedral ARKHE Orchestrator and Prometheus agents (Substrato 9002).

## Packages provided:

1. `cathedral-sdk-py`: the lightweight SDK for Prometheus agents in Python.
2. `cathedral-sdk-rs`: the lightweight SDK for Prometheus agents in Rust.
3. `zk-circuits`: zero-knowledge circuit implementations (e.g., PhysicalConstraintProof using Plonky2).
4. `proto/cathedral/v1/bridge.proto`: gRPC API specification for bridge integration.

## Usage

See specific READMEs in each project directory for more detailed instructions on building and integrating these subcomponents.
